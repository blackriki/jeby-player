# Jeby Player 品牌规范

## 名称

- 正式产品名称：**Jeby Player**，保持空格和大小写。
- 对外介绍：**适用于 Windows 的 Emby 桌面播放器**。
- 英文介绍：**An Emby desktop player for Windows.**
- GitHub 发布目标：[blackriki/jeby-player](https://github.com/blackriki/jeby-player)。仓库尚待创建与验证，正式下载链接以发布后的 Release 为准。

当前仅支持 Emby。Jellyfin 接入并验收后，介绍再更新为“适用于 Windows 的 Emby / Jellyfin 桌面播放器”。名称不随服务器支持范围变化。

## 应用中的使用

窗口标题、首页品牌文字、设置中的关于信息、文件产品属性、安装说明和公开发布材料使用 Jeby Player。同一页面不要混用 Windows Emby Player、Emby Player 等旧产品名。

Emby 仍用于表示服务器类型、账号登录和真实协议名称，不能把服务名称全部替换为 Jeby。现有工程名称、命名空间、可执行文件名以及设置和凭据存储标识可以保留，以避免破坏旧版本兼容性。

品牌更名不等于更换已有数据目录，也不要求用户重新登录或丢失设置。调整存储标识前必须有明确的兼容迁移设计。

## 视觉方向

延续已验收的深色、媒体优先界面和绿色强调色。图标沿用已选择的 A 方案：动作图标以简洁实心风格为主，相同功能复用相同资源，尺寸按所在控件统一。

关于页面复用 `src/EmbyPlayer.App/Assets/app-icon.png` 高清原图，通过资源链接嵌入 UI 程序集；窗口与程序文件使用对应的 `app-icon.ico`。不再使用临时播放按钮作为品牌图标，也不复制另一份图片单独维护。

新名称尚未形成独立 Logo 方案；现有图形不能仅因更名就被标注为已完成授权核验的新品牌标志。公开前需核验图标和图片来源，再决定保留或替换。

## 文案与发布边界

使用简短、清楚的功能描述，避免宣称未验收的服务器兼容性、性能或功能。公开材料应说明客户端连接用户自己的服务器，不提供影视内容、账号或订阅，与 Emby / Jellyfin 没有官方隶属关系。

名称已经由维护者选定；这不代表商标、域名或各平台账号已经注册或完成可用性核验。
